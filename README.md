# Pokédex - Backend

## Sobre o projeto

Este projeto é uma API REST desenvolvida em Java utilizando Spring Boot.

A API é responsável por receber, armazenar, consultar, atualizar e excluir informações de Pokémon em um banco de dados MySQL.

O projeto faz parte de uma aplicação Full-Stack, sendo integrado a um frontend desenvolvido com HTML, CSS e JavaScript.

## Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API

## Banco de dados

O projeto utiliza o MySQL.
